# 目玉焼きになりたい！ - ソースコード

目玉焼きになることを夢見る卵を、部屋の奥にあるフライパンまで運ぶLOST EGG風タイミングアクションゲーム。

卵の周囲を回転する矢印をタイミングよく止めると、その方向へ卵が一直線に飛んでいく。机や椅子、ベッドなどの家具に着地すると、そこを足場にして次の方向を選べる。壁にぶつかると卵が割れ、最後に着地した家具から再挑戦となる。
